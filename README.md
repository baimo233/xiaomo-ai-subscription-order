# AI Subscription Order

小墨Lab · ChatGPT、Claude 与 Gemini 会员展示和演示下单站点。

在线访问：https://baimo233.github.io/xiaomo-ai-subscription-order/

## 本地开发

```sh
npm install
npm run dev
npm run build
```

图标直接来自品牌官方网站，原始来源记录在 `public/brands/sources.json`。图标保留官方颜色。
